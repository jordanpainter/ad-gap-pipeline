# ad-gap-pipeline

## What this is

This is the measurement tool behind the gap analysis in my PhD confirmation
report on audio description for short-form video, at the University of
Surrey. The report ran it over 4,600 YouTube Shorts (10,638 gaps).
This repository holds the code only. Videos, transcripts, model outputs and
the hand-coded corpus labels are not included (see [Data](#data)).

## Pipeline

![Pipeline diagram. A YouTube Short goes into voice activity detection (Silero VAD), which sets every gap boundary. Its speech regions go to transcription (Whisper large-v3-turbo), which supplies the timing of verbal deixis. Its gaps go to three parallel stages: audio classification (PANNs Cnn14), visual description (Qwen3-VL-4B-Instruct, 4-bit) and motion and cuts (frame differencing and histograms). All of these feed one record per gap: 10,638 gaps across 4,600 videos.](docs/pipeline_diagram.png)

`src/batch_analyze.py` runs four stages:

1. **Speech and gaps** (`src/gap_extract.py`). Silero VAD finds speech;
   everything else is a gap. Whisper (`mlx-community/whisper-large-v3-turbo`)
   transcribes the speech regions with word timestamps.
2. **Audio classification** (`src/audio_classify.py`). PANNs (Cnn14) labels
   each gap's audio as silence, music, sfx, ambient or speech, using the
   AudioSet ontology.
3. **Visual description** (`src/frame_describe.py`). Qwen3-VL
   (`mlx-community/Qwen3-VL-4B-Instruct-4bit`) describes frames sampled
   across each gap: subject, action, scene continuity, on-screen text, and a
   short free description.
4. **Motion and cuts** (`src/visual_signal.py`). OpenCV frame differencing
   gives each gap a motion magnitude and flags hard cuts.

`src/deixis_crossref.py` records how far each gap is from the nearest spoken
deictic word ("this", "here", "over there").

## Analysis

The report asks, for each video, whether a description could be placed in a
pause at all. Three mutually exclusive conditions identify videos where it
cannot:

- **Zero-pause**: speech runs for the whole video, so there are no gaps.
- **Zero-speech**: no speech is detected, so the whole video is one gap.
- **Insufficient pause**: the video has speech and gaps, but its longest gap
  is too short for a description of the assumed length.

Description lengths of 3, 6, 10, 15 and 20 words are tested at 160 words per
minute; the report's headline numbers use a six-word description (2.25 s).

Scripts in `scripts/` run no models. They read the outputs in
`data/analysis/`; the two figure scripts that show frames also read the
video:

| Script | What it does |
|---|---|
| `results_summary.py` | Recomputes every descriptive number in the report's gap analysis and prints them by section. |
| `results_figures.py` | Draws the report's results figures into `figures/`. |
| `pick_worked_example.py` | Shortlists videos for the worked-example figure. |
| `worked_example_figure.py` | Draws one video's timeline, one gap's frames and that gap's record from all four stages. |
| `appendix_cut_example.py` | Draws the cut-detection figure (frame pairs and their histograms). |

## Setup

Requires an Apple silicon Mac (Whisper and Qwen3-VL run through MLX),
Python 3.13, and `ffmpeg` and `yt-dlp` on your PATH (e.g.
`brew install ffmpeg yt-dlp`).

```bash
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name ad-gap-pipeline --display-name "ad-gap-pipeline (.venv)"
```

PANNs needs its weights in `~/panns_data/`:

```bash
mkdir -p ~/panns_data
curl -sL -o ~/panns_data/class_labels_indices.csv "http://storage.googleapis.com/us_audioset/youtube_corpus/v1/csv/class_labels_indices.csv"
curl -sL -o ~/panns_data/Cnn14_mAP=0.431.pth "https://zenodo.org/record/3987831/files/Cnn14_mAP%3D0.431.pth?download=1"
```

The Whisper and Qwen3-VL weights (about 4.5 GB) download from Hugging Face
on first use.

Videos are downloaded with `yt-dlp --cookies-from-browser safari`. To use
another browser, change `safari` in `ensure_downloaded()` in
`src/batch_analyze.py`.

## Usage

### One video

Open
[`notebooks/01_gap_pipeline_walkthrough.ipynb`](notebooks/01_gap_pipeline_walkthrough.ipynb),
set `VIDEO_ID` to any YouTube Shorts ID, and run all cells. The notebook is
generated by `notebooks/build_notebook.py`, so edit that and regenerate
rather than editing the notebook.

### Your own videos (gaps only)

Put `.mp4` files in `data/raw_videos/` and run:

```bash
python src/gap_extract.py          # every video -> data/gaps/<video_id>.json
python src/gap_stats.py            # gap duration, position and ratio summaries
```

### Full batch run

`batch_analyze.py --pool all` reads `all_videos_master.csv` from the
directory in `AD_GAP_CORPUS_DIR`. The CSV needs these columns, all but
`video_id` may be blank: `video_id, category, subgenre, seed_channel, title,
url, hand_coded, deixis_present_Y_N_unclear, modality_verbal_gestural_both,
levinson_type, referent_note`.

```bash
export AD_GAP_CORPUS_DIR=/path/to/your/manifest/dir
python src/batch_analyze.py --pool all              # all four stages
python src/batch_analyze.py --pool all --stage 1    # one stage
python src/batch_analyze.py --pool all --limit 20   # first 20 videos, as a smoke test
```

Results go to `data/analysis/`: `gaps_detail.csv` (one row per gap),
`videos_summary.csv` (one row per video) and `failures.csv`. An interrupted
run resumes where it stopped.

## Data

Nothing under `data/` is published, so the analysis scripts can't be rerun
from this repository alone. They show how each number and figure in the
report was computed.

## Known limitations

- VAD uses Silero's default threshold (0.5) and a 0.2 s pad around speech,
  neither validated against hand-labelled speech.
- VAD can mark singing as speech, so a music video with vocals may not count
  as zero-speech.
- PANNs pads short gaps with neighbouring audio, which can pull in speech.
- The deixis detector over-fires ("this is crazy" isn't pointing at
  anything).
- Motion and cut detection are simple, uncalibrated heuristics.
